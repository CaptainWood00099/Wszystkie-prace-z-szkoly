# Wszystkie-prace-z-szkoly
Wszystkie prace które wykonałem w szkole w latach 2023-2024, języki używane przezemnie w tym pracach to PHP, SQL, JavaScript prócz tego znajdują się tam również CSS oraz HTML

Prace mają system nazywania (nr)(nr)[DDMMYYYY], numer był wybierany przez nauczyciela na poczatku roku szkolnego, jeśli jakaś praca ma o 2 liczby mniej, najprawdopodobniej zapomniałem tego dodać
